# EEG_XAI_Depression
Implementation of XAI methods in Depression Classification based on EEG and DL 

This resource contains:
1. Generate a synthetic EEG dataset using SEREEGA tools on EEGLab. 

Download SEREGA and the documentation at: https://github.com/lrkrol/SEREEGA. 

The generated dataset follows the design by Ravindran and Contreras-Vidal (2023), https://doi.org/10.1038/s41598-023-43871-8.   

2. Load, train and evaluate synthetic dataset.

   
3. Load, train and evaluate real EEG datasets in Depression analysis
